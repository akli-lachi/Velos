# Velos
🚀 **Projet Power BI pour l'analyse des vélos 🚲**

## 📌 Description
Ce projet Power BI vise à analyser les tendances de l'utilisation des vélos en fonction de différents critères.

## 📂 Structure du projet
- `Velos.pbip` : Modèle Power BI (sans données).
- `Velos.Report/` : Contient la mise en page des rapports.
- `Velos.SemanticModel/` : Définit les relations et mesures DAX.
